# 🛡️ TrustWall — Apple-Grade Interactive Testimonials Platform

منصة ويب عصرية وخفيفة ومبنية بتصميم أبل الراقي (Apple Design & Glassmorphism) لجمع وإدارة وعرض شهادات وآراء العملاء (Social Proof & Testimonials) وتضمينها في أي موقع أو متجر إلكتروني بسهولة لرفع الثقة والمبيعات.

---

## ✨ المميزات الرئيسية والترقيات الجديدة

- 🍏 **تصميم أبل الراقي (Apple HIG Design System)**: زجاج مصنفر (`backdrop-filter: blur(20px)`), تباين بصري مريح، وظلال متعددة الطبقات.
- 🎬 **حركات تفاعلية فائقة السلاسة (GSAP 3.12)**: كروت ثلاثية الأبعاد متحركة، عدّادات إحصائية ديناميكية، وتأثيرات ظهور متتالية.
- 📱 **معاينة حية ومباشرة (Live Split-Screen)**: أثناء كتابة العميل لشهادته واختيار النجوم في صفحة الجمع، يشاهد كرت تقييمه يتشكل في نفس اللحظة!
- 🎨 **استوديو التضمين (Widget Studio)**: تخصيص مظهر الودجت بـ 4 أنماط فاخرة (فاتح، داكن، زجاجي شفاف، ذهبي ملكي) ونسخ كود الـ HTML الجاهز بضغطة زر.
- ⚡ **دخول تجريبي فوري (One-Click Demo Mode)**: تجربة فورية بدون الحاجة لكتابة بيانات أو تسجيل.
- 💾 **حفظ متكامل للبيانات (Client-Side Persistence)**: يعمل 100% على **GitHub Pages** عبر `localStorage` مع دعم رفع وتخزين الصور بتنسيق Base64، بالإضافة لإمكانية تصدير واستيراد البيانات (JSON Backup).
- 🧱 **لوحة تحكم تفاعلية (macOS-Style Dashboard)**: بحث فوري في الجدران، شريط تحليلات ذكي (عدد الجدران، التقييمات، قيد المراجعة، متوسط التقييم)، وإدارة كاملة للشهادات (قبول / رفض / حذف).
- 🌐 **متوافق بالكامل مع الجوال والحواسيب**: تصميم متجاوب 100% باللغة العربية مع دعم RTL.

## 🚀 النشر على GitHub Pages في دقيقة

1. ارفع المشروع إلى مستودعك على **GitHub**:
   ```bash
   git add .
   git commit -m "Upgrade TrustWall to Apple design & interactive animations"
   git push origin main
   ```
2. في صفحة المستودع على GitHub، توجه إلى:
   **Settings** > **Pages** (القائمة الجانبية).
3. اختر:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` والمجلد `/ (root)`
4. اضغط **Save**.
5. موقعك سيعمل مباشرة على: `https://<username>.github.io/<repo-name>/`

TrustWall/

├── wall.html           # صفحة الجدار العام للعملاء مع الفلاتر والبحث
├── submit.html         # صفحة جمع الشهادات مع المعاينة الحية الفورية
├── embed.html          # استوديو توليد وتخصيص كود التضمين
├── css/
│   ├── style.css       # نظام تصميم أبل، المتغيرات، التنسيقات العامة والـ Bento Grid
│   ├── dashboard.css   # تنسيقات لوحة التحكم وشريط التحليلات
│   ├── wall.css        # تنسيقات صفحة الجدار العام
│   └── submit.css      # تنسيقات صفحة الإرسال والمعاينة الحية
├── js/
│   ├── storage.js      # محرك حفظ البيانات والبيانات التجريبية والصور
│   ├── toast.js        # نظام الإشعارات العائمة التفاعلية (Apple Toasts)
│   ├── auth.js         # منطق المصادقة والدخول التجريبي
│   ├── dashboard.js    # منطق لوحة التحكم والبحث والتحليلات والنسخ الاحتياطي
│   ├── wall.js         # منطق عرض الجدار والفلاتر والبحث
│   ├── submit.js       # منطق صفحة الإرسال والمعاينة الحية وتحديد النجوم
│   ├── embed.js        # منطق استوديو التضمين والأنماط المتعددة

├── package.json        # حزم المشروع
└── README.md           # دليل الاستخدام والتثبيت
