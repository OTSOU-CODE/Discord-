# 🛡️ TrustWall

**منصة جمع وعرض الشهادات التفاعلية (Interactive Testimonials Platform)**

TrustWall يسمح لأصحاب الأعمال والمتاجر الإلكترونية والمستقلين بإنشاء صفحات جميلة لجمع شهادات العملاء (Testimonials) وعرضها في مواقعهم بسهولة واحترافية.

---

## 🌐 النشر المباشر عبر GitHub Pages (Deployment)

تم تنظيم المشروع ليعمل بشكل مباشر وكامل على **GitHub Pages** بدون الحاجة لأي خادم خلفي:

1. ارفع المشروع إلى مستودع على **GitHub**.
2. توجّه إلى إعدادات المستودع (**Settings**).
3. اختر قسم **Pages** من القائمة الجانبية.
4. في خانة **Build and deployment**:
   - **Source**: اختر `Deploy from a branch`
   - **Branch**: اختر `main` (أو `master`) والمجلد `/ (root)`
5. اضغط **Save**.
6. خلال دقيقة، سيكون موقعك منشوراً ويعمل على: `https://<username>.github.io/<repo-name>/`

## ✨ المميزات

- ✅ متوافق 100% مع **GitHub Pages** والاستضافات الثابتة والسحابية
- ✅ حفظ البيانات محلياً للمتصفح (`localStorage`) مع دعم كامل للصور
- ✅ إنشاء جدران (Walls) غير محدودة وتخصيص ألوانها ورسائل الترحيب
- ✅ صفحة جمع شهادات مخصصة لكل جدار (`submit.html?slug=...`)
- ✅ تقييم بالنجوم (1-5) ورفع صور شخصية
- ✅ لوحة تحكم لمراجعة وقبول/رفض/حذف الشهادات (`dashboard.html`)
- ✅ توليد كود تضمين (Embed Widget) لعرض الشهادات في أي موقع خارجي
- ✅ تصميم عصري ومتجاوب بالكامل مع الهواتف والشاشات الكبيرة
- ✅ دعم اللغة العربية واتجاه RTL بالكامل

```
│   ├── wall.css        # أنماط جدار الشهادات
│   └── submit.css      # أنماط صفحة جمع الآراء
├── js/                 # ملفات الجافاسكريبت والمنطق
│   ├── storage.js      # محرك حفظ البيانات واسترجاعها
│   ├── auth.js         # منطق تسجيل الدخول والحسابات
│   ├── dashboard.js    # منطق لوحة التحكم والتحكم بالشهادات
│   ├── wall.js         # منطق عرض الجدار والتقييمات
│   ├── submit.js       # منطق إرسال الشهادات وتحويل الصور
│   ├── embed.js        # منطق توليد وتضمين الودجت

```

## 💻 التشغيل المحلي عبر Node.js (اختياري)

إذا كنت تفضل تشغيل خادم محلي عبر Node.js:

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل الخادم
npm start
```

افتح المتصفح على: `http://localhost:3000`
